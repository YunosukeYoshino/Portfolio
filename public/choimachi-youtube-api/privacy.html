Privacy Policy — choimachi-youtube-api

Last updated: November 8, 2026

Who operates this application

choimachi-youtube-api is a personal, single-user automation tool developed and operated by Yunosuke Yoshino (the "Owner"). It is used exclusively by the Owner to manage his own YouTube channels. It is not a commercial service and has no other users.

Contact: kuremio@gmail.com

What data the application accesses

Through Google OAuth, with the Owner's own authorization, the application accesses the Owner's own YouTube data via the YouTube Data API and YouTube Analytics API, using only these scopes:

  • youtube.upload — to upload and publish videos to the Owner's own channels;
  • youtube.readonly — to read channel and video information for the Owner's own channels;
  • yt-analytics.readonly — to read analytics reports (such as view counts and watch metrics) for the Owner's own channels.

The application does not access data belonging to any other person. It does not collect personal data from third parties, and it contains no advertising, tracking, or third-party analytics.

How credentials and data are stored

The OAuth refresh token and client configuration are stored only on the Owner's own computer, in access-restricted local files. API responses the tool works with (for example, publication records and analytics figures for the Owner's channels) are likewise kept on the Owner's own machines.

Credentials and API data are never sold, never shared with third parties, and never transferred off the Owner's own infrastructure, except for the tool's direct communication with Google's APIs.

How to revoke access

Access can be revoked at any time from the Google Account permissions page: https://myaccount.google.com/permissions. Revoking access immediately stops the tool from using the APIs. Locally stored credentials and data can be deleted by the Owner at any time.

Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
