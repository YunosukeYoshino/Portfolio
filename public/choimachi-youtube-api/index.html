choimachi-youtube-api

choimachi-youtube-api is a personal automation tool built and operated by a single individual, Yunosuke Yoshino, for his own use only. It is not a public service and is not offered to other users.

What it does

The tool connects to the YouTube Data API and YouTube Analytics API, with the owner's own Google account authorization, in order to:

  • upload and publish videos to the owner's own YouTube channels;
  • read channel and video information for those channels;
  • read YouTube Analytics reports for those channels, to review how the published videos perform.

It requests only the following Google OAuth scopes: youtube.upload, youtube.readonly, and yt-analytics.readonly.

Who it is for

Only the owner. No other person can sign in to or use this tool, and it does not collect data from anyone else.
